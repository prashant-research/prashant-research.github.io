Large Dataset Mode

Choose a browser-safe sample. The millions of source rows remain remote; only the sampled rows are brought into Jhatpat Plot.

Large-data safeguard: plotting millions of individual points is usually both memory-intensive and visually misleading because of overplotting. Version 1.0 samples the large source first; use Hexbin, 2D Histogram, density views or aggregation for dense data.

Version 1.0 Notes

Most common plots work in publication and interactive modes. Pair and joint plots are publication-mode features. Matplotlib uses scattered-data triangulation for contour plots, while interactive contour exploration uses colour-mapped points unless the data are already gridded.

Large Dataset Mode samples remote HIGGS and PubChem sources rather than attempting to load millions of rows into browser memory. Dense samples are best viewed with Hexbin, 2D Histogram, density plots or aggregation.

Multiple Y-axes are available, but separate panels are often clearer for unrelated units.

The integrated Gantt Chart Maker supports work packages, tasks, milestones, deliverables, dependencies, progress, baselines, project-wide activities, highlighted periods, captions, CSV/Excel import, saved JSON projects and SVG/PDF/PNG/JPEG export.
